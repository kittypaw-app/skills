# world-time

IANA 타임존별 현재 시각 조회. `worldtimeapi.org` 무료 API, 키 불필요.

## 사용 예시

```
> 한국 시간 몇 시야?
🕒 Asia/Seoul 현재 시각

2026-04-25 18:34:56 +09:00 (Friday)
```

## 설정

| key | 기본값 | 설명 |
|---|---|---|
| `timezone` | `Asia/Seoul` | IANA 타임존 식별자 (예: `America/New_York`, `Europe/London`) |

## API

[timeapi.io](https://timeapi.io) — 무료, 키 없음. (`worldtimeapi.org` 보다 안정적이라 채택)
