# stock-quote

네이버 증권에서 한국 주식 현재가를 즉답하는 skill.
종목명과 6자리 종목코드를 지원하며 API 키가 필요 없습니다.
알림용 `stock-alert` 와 별개로, 사용자가 "삼성전자 얼마야?" 같은 즉답을 원할 때 사용합니다.

## 사용 예시

```
> 삼성전자 주가 알려줘
💹 삼성전자(005930) 현재가

현재가: 73,500원
전일대비: ▲ 1,200원 (1.66%)
KOSPI / 장중
기준: 2026-05-06 10:12:00

_Source: 네이버 증권_
```

```
> 005930 현재가
💹 삼성전자(005930) 현재가

현재가: 73,500원
전일대비: ▲ 1,200원 (1.66%)
KOSPI / 장중
기준: 2026-05-06 10:12:00

_Source: 네이버 증권_
```

## 입력

| 입력 | 예 |
|---|---|
| 종목명 | `삼성전자`, `NAVER`, `카카오` |
| 6자리 종목코드 | `005930`, `035420`, `035720` |
| suffix ticker | `005930.KS`, `035720.KQ` |

## 설정

| key | 필수 | 설명 |
|---|---|---|
| `default_symbol` | — | 사용자가 종목을 명시하지 않았을 때 기본값. 기본 `005930` |

## 데이터

- 종목명 검색: `ac.stock.naver.com`
- 현재가 조회: `m.stock.naver.com`
- 네이버 증권 응답 형식이 바뀌면 스킬도 업데이트가 필요할 수 있습니다.
